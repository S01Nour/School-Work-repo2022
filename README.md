# 🧮 Gestion de Stock - Stock Management with Python

Bienvenue dans ce projet éducatif de **gestion de stock**, développé en **Python** avec une approche progressive à travers plusieurs fichiers et notebooks. Il a pour but d’enseigner les bases de Python, la structuration d’un projet, la manipulation de fichiers, et la programmation par étapes.

- **Python programming**
- **Object-Oriented Programming (OOP)**
- **Jupyter Notebooks**

## 📘 Project Description

This project simulates a simple inventory management system where you can:

- Add new products
- Update stock quantities
- View current inventory
- Search for products
- Track stock levels (e.g. low stock alerts)

It's a great way to learn how to structure code using **classes**, and how to interactively test your logic using **Jupyter notebooks**.

## 🧰 Technologies Utilisées

- 🐍 **Python 3.x**
- 📒 **Jupyter Notebook**
- 🧱 Principes de la **Programmation Orientée Objet (POO)**

    └── partieVII.py


## 🧠 Objectifs pédagogiques

Ce projet est idéal pour les débutants en Python. Il vous permettra de :

- Pratiquer la **programmation structurée**
- Manipuler des **listes globales** et des **fonctions**
- Lire et écrire dans des fichiers (`stock.txt`)
- Expérimenter l'organisation modulaire du code avec plusieurs fichiers `.py`
- Travailler avec des **notebooks Jupyter** pour tester chaque étape
